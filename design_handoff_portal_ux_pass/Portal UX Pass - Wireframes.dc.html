D
All-pages UX / UI improvement & consistency pass
The findings below span every page — dashboard, both calculators, My Pipeline, submission detail (partner + internal), price book landing + detail, both compare tools, and the three admin screens. Each is a review-ready note; nothing here silently redesigns a working page. Three buckets: naming, component & spacing, responsive.
1 · Naming — one label per thing
Drifts todayCanonical
Nav "Compare" · card "VMS Server Comparison" · page "Server Comparison"VMS Server Comparison everywhere
Card "VideoX Quick Compare" · page "VideoX Model Quick Compare"VideoX Quick Compare everywhere
Card "VideoX V5 Price Book" · hero "VIDEOX V5 Products & Prices" drift from the navKeep Products & Prices in nav + card; hero matches
Dashboard card "Calculator" vs hero "Storage & Bandwidth Calculator" (same tool)Hero = full Calculator; card = Quick Calc (see B)
Decided: keep "Products & Prices" — clear and accurate. Card + hero align to it.
2 · Component & spacing — align to the shared ui/ set
FRAGMENTED  Calculator, VMS Server Comparison & VideoX Quick Compare each ship bespoke scoped CSS (their own buttons, selects, tables, headings) instead of the shared Button / Select / Table / Card / MetricTile / StatusBadge.
HEADERS  Three page-header patterns: left "← Back" + ink H1 (Pipeline, Calculator) · centred gold title (Quick Compare) · full-bleed gradient hero (Price Book). → one pattern: back-link + ink H1 + subtitle.
TILES  Metric tiles differ: white "stat" tile w/ navy top-rule (dashboard, admin) vs navy-tint soft tile (Partner Pipeline) vs bespoke bordered totals (Calculator). → one MetricTile.
TABLES  Shared Table chrome (admin, submission detail) vs hand-rolled rows (My Pipeline) vs scoped tables (both compare tools). → one Table.
COLOR  Calculator per-group summary prints purple / green / orange numerals — off the ADR-0075 palette. → navy figures; gold only as the sparing accent (stars, dots, eyebrows).
BUTTONS  Bespoke ac-btn-pdf / ac-btn-quote & vxc pills vs the primary / secondary / outline scale. → Button variants.
