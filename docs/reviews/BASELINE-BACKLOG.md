# Baseline audit backlog

Source of truth for every baseline finding. Created in Group 1 (2026-10-19). Each group updates it. See [`BASELINE-PLAN.md`](./BASELINE-PLAN.md) for the method.

**Rules for this table:**

- One row per root cause. A shared root cause keeps both IDs.
- IDs read `B<slice>-<S|A>-<n>`, where S is security and A is architect.
- Severity uses each reviewer's scale. Security: Critical, High, Medium, Low. Architect: Must fix, Should fix, Consider. A shared row shows both.
- A finding is valid only for the commit it was made on.
- "Fix group" stays blank until Group 6.
