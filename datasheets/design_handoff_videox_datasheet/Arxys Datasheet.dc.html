Notes on this pass
The warranty band sits directly under the product photo on page 1, on a gold-tinted band rather than a boxed callout — it reads as part of the sheet, not an ad. The seal itself is a held circular slot — hairline ring, muted label, nothing drawn that pretends to be the brand mark — sized for the 5-year circle graphic on the product page. Same held-blank logic as the rear-panel decision. The copy on arxys.com is an AVIF, which drops out of PDF and PNG export, so it needs a local PNG before build. On the workstation the same slot is rebuilt at 3 years inside the rail, since a rail sheet has no full-width band to give it — that one needs a matching 3-year graphic, which may not exist yet.
Two things need real data before build: the V800 camera-count rows are illustrative — the existing V800 sheet has no matrix, only the 325-stream / 4,000 Mbit/s ceiling, so those per-resolution rows need to come from the Price Book. And the SW10 usage paragraph is the one piece of copy I had to compose, because the existing workstation sheet doesn't have one — worth a marketing pass or a pointer to existing copy I can swap in.
Gold is load-bearing here: warranty band, section marks, attribute bullets, the workstation's rule. Navy carries every heading, rule and label. That split is what keeps the sheet from looking like the gold-banner Illustrator version while still reading as Arxys.
